# Security Policy

## Reporting a vulnerability

If you find a security issue in this profile repository, please report it privately rather than opening a public
issue. Use GitHub private vulnerability reporting:
<https://github.com/zachshallbetter/zachshallbetter/security/advisories/new>

Include a description of the issue and its impact, steps to reproduce (a minimal example is
ideal), and the affected commit or version.

This project has a solo maintainer. Handling is best-effort with no SLA: there is no guaranteed
response time, and fixes are prioritized by severity as time allows.

## Scope

This repository is the GitHub profile README. It contains no code, dependencies or services.
Reports about the content or the repository's settings are in scope.

## Supported versions

Only the current content of `main` is maintained.
